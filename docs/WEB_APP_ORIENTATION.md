# SS DROPSHIP — architecture site web + applications

## Orientation produit
SS DROPSHIP devient une plateforme de commerce et de suivi accessible par un site web responsive sur téléphone, tablette et ordinateur, installable comme PWA si le socle technique le permet. Le site complète l'expérience mobile et les outils d'administration.

## Parcours web
- Client : accueil, recherche/import de lien produit, commande photo/vidéo, suivi d'achat, entrepôt, chat, paiement et commandes.
- Agent d'achat : demandes, fournisseurs, consolidation, achats et expédition.
- Entrepôt : réception, photos, poids, volume, statut et regroupement de colis.
- Administration : clients, commandes, paiements, langues, transport et support.

## Adaptation écran
- Téléphone : commandes et suivi en cartes verticales, ajout de photos/vidéos avec contrôles adaptés.
- Tablette : liste des commandes et fiche détaillée côte à côte.
- Ordinateur : recherche, tableau de suivi, filtres, détail et pièces jointes en panneaux.

## Compatibilité
Prévoir interfaces français/anglais/turc/espagnol/chinois et les moyens de paiement réellement configurés. Les paiements, douanes, transporteurs et chat ne doivent pas être présentés comme actifs sans intégration vérifiée.
